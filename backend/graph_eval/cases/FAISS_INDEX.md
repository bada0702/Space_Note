# FAISS 인덱스 종류 비교

문서가 20만 건을 넘으면서 단순 Flat 인덱스로는 검색 속도 저하가 심해졌다. 인덱스 종류를 비교한다.

## 후보
- FAISS는 벡터DB 계열의 라이브러리로, IVF와 HNSW를 모두 구현한다.
- IVF는 벡터를 클러스터로 나눠 일부 클러스터만 검색한다. 이번 실험에서 nlist는 1024로 두었다.
- HNSW는 그래프 기반 근사 검색이다. 메모리는 더 쓰지만 IVF의 대안으로 많이 쓰인다.

## 결과
IVF는 검색 속도 저하를 해결했고, 재현율은 nprobe를 16으로 올리니 Flat과 거의 같아졌다. HNSW는 더 빠르지만 인덱스 파일이 커서 이번에는 IVF로 결정했다.

## 운영
인덱스는 재생성 비용이 크니 write_index로 저장하고 시작할 때 read_index로 불러온다.
