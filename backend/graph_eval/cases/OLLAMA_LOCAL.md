# 올라마 로컬 모델 설정 방법

폐쇄망 PC에서 LLM을 돌리기 위한 올라마 로컬 모델 설정 방법을 정리한다.

## 구조
올라마는 내부적으로 llama.cpp에 의존한다. llama.cpp는 GGUF 형식의 모델 파일을 사용한다.

## 모델
테스트 모델은 Gemma다. 올라마로 Gemma를 실행하고, 응답 속도와 한국어 품질을 확인했다.

## 폐쇄망 문제
인터넷이 막혀 있어서 `ollama pull`로 받을 수 없었다(모델 다운로드 불가). 외부 PC에서 GGUF 파일을 받아 옮긴 뒤 Modelfile로 등록해서 모델 다운로드 불가 문제를 해결했다.

## 하드웨어
GPU 메모리는 8GB라서 4비트 양자화 모델만 올라간다. 더 큰 모델은 CPU로 넘어가면서 크게 느려진다.
