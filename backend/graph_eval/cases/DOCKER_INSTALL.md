# 개발 서버에 도커 설치 방법

새 개발 서버에 도커 설치 방법을 정리해 둔다. 서버 OS는 우분투 22.04다.

## 설치
1. 기존에 깔린 구버전 패키지를 지운다.
2. apt 저장소에 공식 키와 저장소 주소를 추가한다.
3. apt로 docker-ce 패키지를 설치한다.

도커는 우분투 위에서 동작하고, 설치 후 `systemctl status docker`로 데몬이 떠 있는지 확인한다.

## 권한 오류
일반 사용자로 `docker ps`를 치면 권한 오류(permission denied)가 난다. 사용자를 docker 그룹에 추가하면 권한 오류가 해결된다. 그룹 변경 후에는 다시 로그인해야 적용된다.

## Compose
여러 컨테이너를 같이 띄우려고 Docker Compose도 설치했다. Docker Compose는 도커에 의존하는 도구라 도커 엔진이 먼저 있어야 한다.

## 메모
- 방화벽 규칙은 별도 문서 참고
- 이미지 저장 위치가 루트 파티션이라 용량을 자주 확인할 것
