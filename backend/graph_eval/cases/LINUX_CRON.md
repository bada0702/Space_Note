# 크론 설정 방법과 로그 정리

리눅스 서버에서 주기 작업을 돌리기 위한 크론 설정 방법을 정리한다.

## 크론
크론은 리눅스에서 동작하는 스케줄러다. `crontab -e`로 작업을 등록하고 `crontab -l`로 확인한다.

## 정리 스크립트
매일 새벽 오래된 임시 파일을 지우는 cleanup.sh를 만들었다. cleanup.sh는 Bash로 작성했고, 크론이 매일 3시에 실행한다.

## 로그 문제
애플리케이션 로그가 계속 쌓여서 디스크를 많이 차지했다(로그 파일 증가). logrotate를 설정해서 로그 파일 증가 문제를 해결했다. logrotate도 리눅스에서 기본으로 제공된다.

## 설정값
- 로그는 7일치만 보관
- 압축은 gzip
- 크론 작업 결과는 메일 대신 파일로 남김
