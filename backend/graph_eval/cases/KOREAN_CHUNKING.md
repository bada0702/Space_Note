# 한국어 문서 청킹 개선

RAG 답변에서 문장이 중간에 잘린 근거가 자주 나와서 청킹 방식을 바꿨다.

## 문제
글자 수로만 자르니 "~했습니다." 같은 문장 끝이 다음 청크로 넘어가는 문장 경계 깨짐이 많았다.

## 방법
- Kiwi(kiwipiepy)로 형태소 분석을 하고, Kiwi가 구현한 문장 분리 기능으로 문장 경계를 찾는다.
- 형태소 분석으로 문장 경계 깨짐을 해결했다.
- 청킹은 tiktoken을 사용해 토큰 수 기준으로 자른다. 청크 크기는 500토큰, overlap은 50토큰이다.
- RAG는 이 청킹 결과를 사용한다.

## 확인
샘플 질의 20개로 context precision을 비교했고, 잘린 근거가 눈에 띄게 줄었다. 영어 기준 기본값은 한국어에 그대로 맞지 않으니 직접 확인해야 한다.
