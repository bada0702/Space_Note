# 야간 백업 스크립트 점검 메모

테스트 서버(가상 환경)의 야간 백업이 이틀 연속 실패해서 원인을 정리한다.

## 현재 구조
- 운영체제는 AIX이고, 시스템 이미지는 mksysb로 만든다.
- 백업은 backup.ksh 스크립트가 담당한다. backup.ksh는 ksh로 작성했고, 내부에서 mksysb를 호출한다.
- mksysb는 AIX 위에서만 동작하는 명령이라 다른 서버로 옮길 수 없다.
- 만들어진 이미지는 NFS 공유 디렉터리에 저장한다. backup.ksh가 NFS를 마운트한 뒤 복사한다.
- 실행은 cron이 매일 새벽 2시에 backup.ksh를 돌린다.

## 실패 원인
로그를 보면 /tmp의 디스크 공간 부족이 백업 실패의 원인이었다. 이미지 임시 파일이 /tmp에 쌓이면서 공간이 모자랐다.

## 조치
- 임시 디렉터리를 별도 파일시스템으로 변경
- 스크립트 시작 전에 남은 공간을 확인하고 부족하면 바로 종료하도록 수정
- GNU 전용 옵션(sed -i 등)은 AIX에서 동작하지 않으므로 쓰지 않는다
