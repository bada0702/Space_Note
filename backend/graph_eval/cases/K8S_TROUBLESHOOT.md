# 파드 재시작 반복 장애 정리

스테이징 클러스터에서 API 파드가 계속 재시작되는 장애가 있었다. 아래는 원인과 조치다.

## 증상
- 쿠버네티스 대시보드에서 파드 상태가 CrashLoopBackOff로 표시됨
- kubectl describe로 보면 마지막 종료 사유가 OOMKilled

## 원인
컨테이너의 메모리 부족이 CrashLoopBackOff의 원인이었다. 배치 작업이 들어오면 메모리를 순간적으로 많이 써서 커널이 프로세스를 죽였다.

## 조치
- resource limits를 다시 설정해서 메모리 부족을 해결했다. requests 512Mi, limits 1Gi로 올렸다.
- kubectl로 롤아웃 상태를 확인하고, 문제 없으면 운영에도 같은 값을 적용한다.

## 참고
파드는 쿠버네티스에서 배포되는 가장 작은 단위이고, 컨테이너 하나 이상을 포함한다. kubectl은 쿠버네티스 API 서버와 통신하는 명령줄 도구다.
